# hh.ru Capture

[English](README.en.md) · [Установка](docs/setup.md) · [Проверка качества](docs/evaluation.md)

Локальный OCR для коротких кириллических надписей на искривлённой строке. Проект объединяет генератор синтетических изображений, выпрямление текста и дообученный распознаватель на основе PaddleOCR. На входе файл или папка с изображениями, на выходе JSONL с текстом и оценкой уверенности.

Текущая версия рассчитана на изображения 250×90 с двумя группами кириллических букв. Результат приводится к нижнему регистру; пробелы и буква ё сохраняют значение. Это специализированный компонент, который нужно отдельно проверять на данных конкретного продукта.

Название проекта не означает связи с HeadHunter. Проект не является официальным продуктом hh.ru. В составе есть только обработка локальных изображений; интеграция с сайтом не реализована.

## Как работает

1. OpenCV выделяет штрихи текста, оценивает изгиб строки и выпрямляет изображение.
2. Распознаватель PP-OCRv5 обрабатывает два варианта обрезки. Один использует жадное CTC-декодирование, второй поиск по лучу без словаря слов.
3. Конфигурация выбирает ответ по оценке модели. Дополнительная исходная модель может вернуть одну пропущенную букву при признаках обрезанного штриха и выполнении ограничений на текст.
4. CLI записывает поля `file`, `text`, `confidence`. Значение `confidence` не является вероятностью правильного распознавания всей строки.

Веса и их SHA-256 закреплены в [конфигурации](experiments/recognition_v2/frozen_config.json). Проверка хеша выполняется при загрузке.

## Запуск

Проверенная среда: Windows x64, Python 3.13, PaddlePaddle 3.2.0. [Инструкция установки](docs/setup.md) включает загрузку весов из приватного GitHub Release.

```powershell
python recognize.py .\input --device cpu --output results.jsonl
```

Пример структуры одной записи (путь и текст приведены для иллюстрации):

```json
{"file": "input/sample.png", "text": "лесная тропа", "confidence": 0.94}
```

Генератор создаёт искривлённые надписи со сдвигами отдельных букв, фоновым шумом и линиями:

```powershell
python generator.py --count 100 --seed 42 --output synthetic_v4
```

По умолчанию он использует установленные в Windows шрифты. Файлы шрифтов не входят в репозиторий. Встроенный список фраз предназначен для демонстрации; для обучения нужен отдельный корпус.

## Качество

Точность ниже означает полное совпадение строки после приведения регистра и нормализации пробельных символов. Внутренние пробелы учитываются.

| Набор | Изображений | Исходная модель | Текущая версия |
| --- | ---: | ---: | ---: |
| Новый синтетический тест | 1 000 | 73,2% | 95,2% |
| Новый стрессовый тест | 500 | 41,2% | 92,6% |
| Ранее подготовленный синтетический набор | 1 000 | 85,3% | 97,0% |

Для обучения использовано 7 500 изображений, для настройки 600. Слова новых финальных тестов не пересекаются с обучающими и проверочными наборами. Девять знакомых исходных изображений распознаются полностью, но использовались при разборе ошибок и служат регрессионной проверкой. По ним нельзя оценивать точность на новых изображениях с сайта.

[Методика и ограничения](docs/evaluation.md) описывают историю настройки и границы этих результатов. Исходные датасеты и контрольные изображения в репозиторий не входят.

## Состав и статус

- `recognize.py`, `recognition_*.py`: CLI, загрузка модели и декодирование.
- `rectifier.py`: геометрическое выпрямление строки.
- `generator.py`: синтетические изображения с воспроизводимым seed.
- `PaddleOCR/ppocr`: сохранённый код upstream, необходимый для архитектуры модели.
- `test_*.py`: проверки генератора и семантики распознавания.

Это исходники текущей версии локального распознавателя. Обучающие эксперименты, их журналы и окружения остаются в рабочем архиве. Репозиторий не содержит HTTP API, измерений производительности сервиса или обещаний SLA.

Открытая лицензия на собственный код проекта не предоставлена. Условия сторонних компонентов сохранены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Перед расширением распространения проекта нужно отдельно определить условия для собственного кода, весов и используемых данных.
